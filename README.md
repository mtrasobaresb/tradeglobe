# Global Trade Visualizer

An interactive 3D WebGL data visualization platform inspired by the Arms Globe project, mapping macroscopic bilateral trade flows across the world.

## Tech Stack
* **Language:** TypeScript (Structured under the Google TypeScript Style Guide)
* **Build Tool:** Vite
* **3D Graphics Engine:** Globe.gl / Three.js
* **Data Processing:** D3.js

## Getting Started

### Prerequisites
* Node.js (v26 or higher recommended)
* npm

### Installation & Local Development
1. Clone the repository
2. Install dependencies: `npm install`
3. Run local server: `npm run dev`
4. Lint and check style: `npm run check`
